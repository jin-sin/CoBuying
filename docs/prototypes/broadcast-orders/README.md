# 방송판매 시안 v2.2.0

이 시안은 [공통 문서 묶음 v2.2.0](../../plans/broadcast-orders/stage-versions.md)의 가상 화면이다. 실제 구현 단계 버전은 별도로 관리한다.

실제 B01 직원 화면은 고객 닉네임 서버 검색과 고객/주문 목록의 `더 보기`를 제공한다. 이 시안에는 예시 고객 2명만 있어 검색·선택 흐름을 클릭해볼 수 있으며 서버 페이지 부하나 판매자별 권한 검증 화면은 아니다.

담당자 화면의 ‘담당자 참여 체험’에서 코드 생성→보조 참여→접근 회수를 클릭할 수 있다. 이 흐름은 가상 전환이며 실제 JWT·코드 만료·권한 회수의 구현 증거는 아니다.

2026-09-28 상세 화면 보완. 2026-09-23 판매자 요구사항 반영. **가상 메모리 UI**로 새로고침 시 초기화하며 실제 고객/주문/송금/주소를 저장하지 않는다. 전체 서비스 구현 완료가 아니다. 실제 직원 저장 기능 개발은 별도 Flutter/RPC 코드다.

```sh
python3 -m http.server 59427 --bind 127.0.0.1 --directory docs/prototypes/broadcast-orders
```

http://localhost:59427/ 를 연다. localhost는 실행 중인 이 컴퓨터에서만 접근 가능하다. 외부 배포/공유 링크가 아니다.

## 체험

1. 담당자 → 방송·상품: 사전 비공개 상품, 소개 후 공개, 다중 현재 코디. 빠른 등록/접수 전 수정/삭제/복구. 수정 후 비공개 전환·재공개, 번호 보존. 거래처·가격·옵션·택포 제외.
2. 빠른 입력: ‘몽’ 검색 → 몽이맘 선택 → 저장. 반복하면 같은 옵션도 별도 행. 상품/옵션 유지.
3. 고객 화면: 공개 상품만 노출, ‘핑크 7호 두개’ 한 줄 추가 → 담당자 처리함. 고객 수정 요청 → 담당자 정정 → 고객 최종 옵션.
4. 고객·정산: 국가 선택 후 미정산 주문 발행. 선입금 차감, 양 통화, 배송비/택포. 한 줄 미확정 주문은 먼저 확인해야 한다.
5. **320위안 업무 예시**: 몽이맘10개/320위안, 몽베베1개/미입금. 고객 주소 입력 → 안내 동의 → 가상 캡처300 → 담당자 수취확인 → 고객 추가20 → 담당자 확인.
6. 거래처 발주 → 합산: 입금완료10개만, 미입금1개 제외. 중복 발주 방지. 발주표와 고객표가 같은 데이터를 사용.
7. 입고·출고: 6개 입고 → 주문순 배정 확인 → 불량1 분리 → 정상5 출고/송장1. 잔여4 입고+교환1 입고 → 나머지5 출고/송장2.
8. 15일 후 체험: 미송이 남아 있으면 고객별14일 알림, 미입금은 취소 검토. 자동 취소 안 함. 주소/증빙/추가/수정 알림은 업무 반영 전 유지.

## 한계

새 기기 요청·확인·활성화·회수는 메모리 상태 체험이며 실제 인증이 아니다. 송금 캡처는 가상 저장 체크이고 파일 업로드가 아니다. 선입금·수취·환불은 실제 거래 대조를 하지 않는다. 수취 안내는 가짜 문구이며 QR/계좌를 연결하지 않는다. 내보내기는 미리보기·생성 완료 체험까지, 실제 XLSX 파일을 만들지 않는다. 새로고침하면 모두 초기화한다. 실제 파일/기기 보안/네트워크 오류/중국 접근/20건 현장 입력 속도는 후속 구현 검증이다.

## 추가 화면

- **방송 회차**: 새 방송 생성, 날짜/종류/준비·접수·마감, 회차 전환. 카탈로그/빠른입력/신규 청구는 선택 방송, 업무 처리함과 물류는 전체 방송 기준.
- **고객·정산**: 선입금 수취 기록/원장, 관리자 주소 정정과 사유, 기기 접근 회수. 주문 정정은 단가/옵션/수량/해당상품 취소, 고객 요청 반려도 가능.
- **수취 설정**: 한국 계좌·위챗페이·알리페이 안내. 확인 후 활성화, 새 청구에만 적용.
- **입금 확인**: 증빙 추가 확인 요청→고객 보완, 350위안 수취→30위안 환불 예정→실제 환불 확인 기록. 고객은 확인수취·환불·순수취를 확인.
- **새 기기 체험**: 고객 개인정보를 숨김→확인 요청→직원 처리할 일에서 기존 위챗 확인→고객 일회용 활성화 체험.
- **관리표 내보내기**: 거래처 발주표/내부 고객관리표 선택, 거래처 필터, 열·행 미리보기, 개인정보 범위 확인. 실제 다운로드는 B05.
