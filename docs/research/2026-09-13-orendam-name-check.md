# 오렌담마켓 이름 예비 확인

확인일: 2026-09-13 / Codex / D7. 사용자 요청: ‘오렌담마켓 확인해줘’. 공개 사용 사례와 KIPRIS 국내 상표를 조회했다. 조사 당시 서비스명은 **오렌지마켓**이었으며 D7은 이름을 변경하지 않았다. 이후 D8에서 사용자가 **오렌담마켓 / 오렌담 / ORENDAM**을 채택하고 실제 서비스 반영을 지시했다. 현재 표기는 [브랜드 기준](../brand.md)을 따른다. 아래 조사 결과와 권리 확인 범위는 그대로 보존한다.

## 판단

**후보로 유지할 만하다. 동일 이름의 직접적인 검색 중복은 이번 조사에서 발견하지 못했다.** 다만 근접 이름인 ‘오렌다’의 등록 상표와 ‘오렌다몰’의 온라인 판매 사례가 있으므로, 이 조사만으로 상표 등록 가능성이나 사용에 문제가 없음을 확정하지 않는다.

이름에 대한 제품 관점의 판단: ‘오렌담’은 현재 오렌지 색상과 ‘담다’라는 구매 행동을 연결할 수 있고, ‘마켓’을 붙이면 쇼핑 서비스라는 성격이 드러난다. 처음 듣는 고객에게 뜻이 바로 전달되는지는 아직 시험하지 않았다. 검색 구분 가능성에 대한 긍정적인 평가는 아래 제한된 공개 검색 결과에 근거한 추론이다.

## 공개 사용 사례

- 검색한 표현: `"오렌담마켓"`, `"오렌담"`, `"오렌담" 상표`, `"ORENDAM"`, `"오랜담"`, `"오렌다" 상표 쇼핑`, `"오렌담" site:kipris.or.kr`, `"오렌담마켓" OR "오렌담 마켓" 쇼핑`.
- 이번 검색에서 ‘오렌담마켓’ 또는 ‘오렌담’이라는 국내 쇼핑 브랜드의 직접적인 사용 사례는 찾지 못했다. 검색엔진이 수집하지 않은 상호·앱·SNS·신규 서비스까지 미사용이라고 증명하는 결과는 아니다.
- 근접 이름 **오렌다몰**은 옥션에 판매 페이지가 있다. 판매자 상호는 ‘오렌다’로 표시되고, 의류·가방·신발 등을 판매 목록에서 확인했다. 따라서 이름과 판매 분야를 함께 비교할 대상이다. 이 판매자가 아래 등록 상표의 권리자라고 판단할 근거는 확보하지 않았다. [옥션 오렌다몰](https://stores.auction.co.kr/ORENDA).

## KIPRIS 조회 방법과 결과

[KIPRIS 지식재산정보 검색](https://www.kipris.or.kr/khome/search/searchResult.do)을 브라우저에서 열어 **상표 → 국내**를 선택했다. 상단 검색창에 각 단어를 개별 입력했으며 결과 내 재검색은 끈 상태였다. 권리구분·상표유형·행정상태는 전체, 상품류 제한은 두지 않았다. 행정상태를 펼쳐 출원·공고·등록·거절·무효·소멸·취하·포기 모두 선택된 것을 확인했다.

상표명칭 전용의 정확 일치 검색이나 모든 유사 발음에 대한 조사는 아니다. **아래 숫자는 입력한 검색어에 대한 국내 검색 결과 건수**다. 일반 검색에는 출원인·권리자 등 다른 항목에 검색어가 포함된 결과도 나올 수 있다. 결과 페이지 주소만으로 검색 조건이 복원되지 않을 수 있으므로 재확인 시 같은 조건과 검색어를 입력한다.

| 검색어 | 국내 결과 | 화면에서 확인한 내용 |
|---|---:|---|
| 오렌담마켓 | 0건 | 해당 검색어의 결과 없음 |
| 오렌담 | 0건 | 해당 검색어의 결과 없음 |
| ORENDAM | 0건 | 해당 검색어의 결과 없음 |
| 오랜담 | 0건 | 해당 검색어의 결과 없음 |
| 오렌다 | 20건 | 아래 근접 상표 및 출원인 등에 단어가 포함된 다른 상표가 함께 조회됨 |
| ORENDA | 24건 | 국내 결과 기준. 상단 상표 탭의 국내외 합계 230건과 구분 |

‘오렌다’와 ‘ORENDA’에서 실제 결과 목록이 표시되는 것도 확인했다. 모든 검색이 빈 화면으로 끝나는 상태를 ‘미등록’으로 해석한 것은 아니다. 검색 결과 0건은 동일 이름의 공개 검색 결과를 찾지 못했다는 뜻이며, 유사 상표의 부재나 법적 사용 가능 판정을 뜻하지 않는다.

### 비교할 근접 상표

아래는 목록에서 확인한 대표 항목이며, 전체 선행상표 목록이 아니다. 20건 또는 24건 전체가 ‘오렌다’라는 등록 상표라는 뜻도 아니다.

| 오렌다 (orenda) | 4020200162987 | 05 | 등록 | 결과 목록 |

출원번호 **4020180164977**의 상세 화면은 최종권리자 ‘주식회사 에스쁘아’, 등록번호 **4015193030000**, 등록일 **2019-09-09**, 법적상태 ‘등록’으로 표시됐다. 지정상품에는 화장품·립스틱 등이 포함됐다. 다른 근접 항목들의 개별 지정상품·등록사항·행정 이력 전체를 대조한 것은 아니다. 위 출원번호로 KIPRIS에서 재확인할 수 있다.

이 결과만으로 온라인 의류 중개 서비스와 충돌한다고 판단하지 않는다. 반대로 상품류 번호가 다르다는 이유만으로 충돌하지 않는다고 판단하지도 않는다. 동일·유사 상표와 지정상품/서비스의 관계를 함께 검토해야 한다. [지식재산처 상표의 이해](https://www.moip.go.kr/ko/kpoContentView.do?menuCd=SCD0200154).

## 출시명 확정에 남은 확인

1. 실제 제공할 온라인 거래 중개와 상품 소매 서비스의 지정 범위를 정하고, ‘오렌담/ORENDAM’과 ‘오렌다/ORENDA’ 등을 비교하는 선행상표 검토를 진행한다. 온라인 마켓플레이스 제공은 국제 분류 35류에 포함되므로 우선 검토할 분야다. 필요한 추가 분류는 실제 사업 범위에 따라 정한다. [WIPO 2026 Nice 분류 35류](https://nclpub.wipo.int/esen/pdf-download.pdf?classNumber=35&dateInForce=20260101&lang=en&tab=&viewMode=flat).
2. 명칭·발음·로고와 개별 권리의 지정상품/서비스·현재 상태를 종합해 출원 전 변리사 검토를 받는다. 이번 일반 단어 검색을 정식 선행상표 조사로 대체하지 않는다.
3. 중국 상표·중문명, 도메인, 앱스토어와 SNS 이름 확보 여부는 별도다. 이번에 확인 또는 확보한 것으로 안내하지 않는다.

이번 단계는 이름 후보의 예비 확인 완료다. 서비스명 재변경, 상표 출원, 도메인 등록, 운영 배포, 업체 문의는 수행하지 않았다.
