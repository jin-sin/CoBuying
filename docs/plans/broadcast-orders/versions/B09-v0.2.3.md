# B09-v0.2.3 · 임시 HTTPS 기기 시험 환경

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. 이전 [v0.2.2](B09-v0.2.2.md)의 실제 Cloud HTTP 검증을 유지한다.
- 테스트 Supabase만 연결한 Flutter debug 웹 빌드와 `test-web-host.mjs`를 준비했다. 로컬 Node 호스트가 Flutter 정적 파일과 고객 게이트웨이 API를 같은 출처로 제공하고, 공식 Cloudflare Quick Tunnel의 무작위 HTTPS 주소를 사용한다. 서버 전용 키는 서버 프로세스에만 전달하며 브라우저 번들·저장소·로그에 넣지 않는다. 호스트는 시작 4시간 뒤 종료된다.
- 외부 HTTPS에서 health 200, 관리자/보조 링크의 로그인 화면, 고객 링크의 기기 접근 안내를 확인했다. 390px 브라우저 폭에서 로그인·고객 접근 화면이 맞게 배치됐다. 고객 URL만으로 API 조회는 401, 다른 Origin POST는 403을 확인했다. Flutter 웹 링크는 `/seller/...` 경로가 아닌 기존 `/#/seller/...` 해시 경로를 써야 한다.
- 시험 프로젝트의 익명 로그인은 현재 꺼져 있다. 관리자/보조가 실제 기기에서 로그인하고 판매자 테스트 권한·초대·고객 전용 링크를 발급하는 단계는 아직 수행하지 않았다. 고객/직원 전체 화면의 실제 조작과 한 방송 30단계·중국 회선은 여전히 미검증이다. 터널은 임시 주소이며 기기 시험 중 컴퓨터·호스트가 켜져 있어야 한다. 운영 DB·운영 웹·실거래·고객 메시지는 변경하지 않았다.
