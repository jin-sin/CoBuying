# B04-v0.2.1 · 동일 수취 건 증빙 보완

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.2.0](B04-v0.2.0.md) 기록은 유지한다.
- 관리자 보완 요청은 사유와 멱등 키를 남기고 `needs_info`로 전환한다. 고객은 활성화된 기기에서 사유를 보고 새 캡처를 비공개 저장한 뒤 같은 receipt ID에 붙인다. 과거 캡처 이력은 보존하고 이전 캡처를 새 입금으로 다시 신고할 수 없게 했다. 보완 중 실수취 확정도 서버에서 거절한다.
- 로컬 PGlite 고객/관리자 권한·보완 재시도·중복 집계 방지, Flutter 정적 분석 통과. PostgreSQL/PostgREST HTTP 검증 결과는 작업표에 기록한다.
- 실제 Cloud Storage·브라우저 파일 업로드/다운로드, 수취 계정 안내 스냅샷과 실기기 검증이 남았다. 운영 DB·Storage·웹은 변경하지 않았다.
