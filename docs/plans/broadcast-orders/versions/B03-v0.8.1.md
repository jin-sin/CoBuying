# B03-v0.8.1 · 전량 상품 제외

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. 이전 [v0.8.0](B03-v0.8.0.md)의 기능을 유지한다.
- 관리자 상품 제외에서 청구 상품을 모두 선택하면 빈 정산서를 발행하지 않고 기존 청구를 무효화한다. 주문 원본과 청구 이력을 보존하고 선입금 배분을 되돌린다. 같은 명령 키 재시도는 같은 결과를 반환한다. 화면 버튼도 전량 선택 시 ‘정산서 무효화’로 표시한다.
- 로컬 고객/게이트웨이 시험에 전량 제외·멱등·선입금 반환 사례를 추가했다. 테스트 Cloud·실제 Storage·브라우저/실기기 검증은 남는다. 운영 DB·웹에는 적용하지 않았다.
