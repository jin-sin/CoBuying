# B09-v0.1.0 · 시험 운영 검증표 착수

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0.
- [30개 시험 시나리오](../validation-b09.md)를 로컬 자동 검증 근거와 실제 현장 결과로 분리했다. 자동 검증은 여러 독립 테스트이며 한 방송의 로그인 화면 연속 시험이 아니다.
- 테스트 Supabase에는 B01까지만 적용되어 B02~B08 화면 연속 시험 전 마이그레이션/비공개 Storage 적용이 필요하다. SQL 편집기에서 B02 테이블이 없는 것은 읽기 전용으로 확인했다. 브라우저 자동화의 로컬 SQL 파일 열기는 URL 보안 정책으로 거절되어 그 경로로 적용하지 않았다. 운영 DB·웹에는 적용하지 않았다.
- [테스트 Cloud SQL 묶음](../generated/test-cloud-b02-b08.sql)을 생성했다. 24개 증분 파일을 한 트랜잭션으로 묶고 B01 필수/B02 미적용 검사를 포함한다. 로컬 PGlite에서 묶음 적용·재실행 거부를 통과했다. 이 파일과 비공개 Storage 버킷 SQL은 **아직 Cloud에 적용하지 않았다**.
- 남은 게이트: 테스트 Cloud/Storage 적용 후 실제 로그인·브라우저 1~29번, 약20건 현장 입력 속도, 중국 VPN 없는 iPhone/Android 일반 브라우저 30번과 실패/재시도·권한 검증. 이 증거 없이 B09 또는 전체 MVP 완료로 표시하지 않는다.
