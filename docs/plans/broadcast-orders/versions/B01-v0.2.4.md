# B01-v0.2.4 · 카카오 없는 참여 링크 화면 검증

- 기록 시점: 2026-09-28. 상태: **진행 중**. 공통 문서 묶음: v2.2.0. 이전 [B01-v0.2.3](B01-v0.2.3.md)은 변경하지 않는다.

## 변경·검증

- 개발/테스트 빌드에서 `BROADCAST_TEST_AUTH=true`일 때만 익명 테스트 로그인 버튼을 표시한다. 릴리스 빌드에는 표시하지 않는다. 운영 로그인 설정은 변경하지 않았다.
- 인증 경로의 `from` 보존을 공통 함수로 분리해 직원 링크의 `code`를 로그인 후에도 유지한다. 외부 URL로의 로그인 후 리다이렉트는 거부한다.
- `npm run test:join-link --prefix tools/broadcast-tests` 통과: 실제 로그인·참여 Flutter 화면을 사용해 링크 진입 → 테스트 로그인 → 코드 자동 입력 → 참여 RPC 요청 → 판매자 방송 화면 이동을 확인했다. 인증/서버 응답은 **로컬 모의 HTTP**이며, 앞선 Cloud Auth JWT→RPC 시험과 구분한다.
- `flutter analyze --no-pub` 대상 파일 통과, 계획 버전 검사와 `git diff --check` 통과.

## 남은 게이트

- 별도 Cloud 테스트 프로젝트에서 실제 앱 화면으로 동일 링크를 열어 테스트 Auth 세션·RPC를 연속 검증하는 작업은 아직 하지 않았다. Cloud 프로젝트 익명 로그인은 꺼져 있다.
- 실제 카카오 OAuth 복귀, 두 물리적 휴대폰의 접근 회수 즉시 반응, 프로세스 종료/재시작 및 상품당 약 20건 현장 입력 속도는 미검증. B01-v1.0.0 완료로 표시하지 않는다.
- 운영 DB/웹/고객 메시지 변경 없음.
