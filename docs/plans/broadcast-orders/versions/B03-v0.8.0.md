# B03-v0.8.0 · 미입금 배송국가 정정

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.7.0](B03-v0.7.0.md)의 QR/청구 경로를 유지한다.
- 미입금·미증빙·미발주 청구의 배송국가를 관리자가 사유와 함께 정정하면, 옛 청구/선입금 배분 이력을 보존하고 새 판본의 환율·배송비를 재계산한다. 기존 주소는 비우고 고객이 새 국가 주소와 최종 내용을 다시 확인한다. 이미 증빙·송금·입금·발주가 시작된 건은 자동 정정을 거절한다.
- KR→CN, 배송비·새 주소/동의, 권한·멱등·잠금 사례를 포함해 로컬 고객/게이트웨이 20/20과 Flutter 정적 분석을 통과했다. 실제 Storage·브라우저·기기/중국망 시험은 남는다. 운영 DB·웹에는 적용하지 않았다.
