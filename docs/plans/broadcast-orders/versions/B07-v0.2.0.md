# B07-v0.2.0 · 고객 출고 조회 연결

- 기록: 2026-09-28. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.1.0](B07-v0.1.0.md)의 출고 SQL/검증은 그대로 보존한다.
- 고객 게이트웨이 `GET /customer/:locator/shipments`와 Flutter 고객 화면의 출고/송장 목록을 연결했다. 활성 기기 쿠키를 검사하고 타 고객 locator 사용을 거부한다.
- 로컬 게이트웨이 HTTP·Flutter 정적 분석과 기존 PGlite 두 송장/주소 스냅샷 시험 통과. 실제 웹 기기·중국 고객·택배사 송장 형식, 관리자 출고 화면 및 고객 준비 잔량 UX는 미검증이다. 운영 배포/DB 적용 없음.
