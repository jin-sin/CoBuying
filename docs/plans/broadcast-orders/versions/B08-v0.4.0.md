# B08-v0.4.0 · 처리함 집계와 취소 재시도 복구

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.3.0](B08-v0.3.0.md)의 72시간·14일 업무 경계를 유지한다.
- 관리자 처리함에 고객 요청·입금 확인·취소 검토·장기 미송 건수를 표시한다. 미입금 취소는 서버 전송 전에 요청 원문/멱등 키를 기기에 보존해 앱 재시작 후 같은 취소만 재확인한다. 미확인 취소가 남으면 다른 취소를 시작할 수 없다.
- Flutter 방송 화면 정적 분석 통과. 실제 기기 재시작·네트워크 응답 유실, 다중 탭, 대량 처리함 페이지네이션은 남는다. Cloud/운영 DB·웹에는 적용하지 않았다.
