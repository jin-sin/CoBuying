# B03-v0.3.0 · 상품 제외 청구 재발행

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.2.1](B03-v0.2.1.md)의 수취 안내 스냅샷은 유지한다.
- 관리자가 미입금 청구의 상품 행을 선택해 제외하고 사유를 입력하면, 서버가 이전 청구를 `superseded`로 남기고 같은 청구 시리즈의 다음 판본을 발행한다. 주문 원문/순번과 옛 청구 행 스냅샷은 유지하며, 제외 주문은 취소 표시와 감사 기록을 남긴다. 새 판본의 배송비·환율·선입금 배분을 다시 계산하고 고객 동의를 새로 받는다.
- 증빙 예약·송금 신고·입금 확인·발주가 한 건이라도 시작되면 재발행을 거절한다. 빈 청구로 끝나는 전체 제외도 거래를 롤백한다. 관리자 화면은 현재 판본/잠금 상태/제외할 행을 보여주고, 고객 화면은 현재 발행된 판본을 중심으로 표시한다.
- 로컬 SQL·고객/관리자 시험과 PostgreSQL/PostgREST HTTP, Flutter 정적 분석 결과는 작업표를 따른다. 실브라우저 조작·다중 관리자 경쟁/실기기는 미검증이다.
- 남은 B03: 청구된 고객 수정 요청과 재발행 결과의 처리함 연결, 단가·수량·주소/배송국가 정정, 선입금 실수취 정정·반환, QR 안내. 운영 DB·웹에는 적용하지 않았다.
