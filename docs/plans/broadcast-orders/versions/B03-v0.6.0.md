# B03-v0.6.0 · 선입금 오기입 무효화

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.5.0](B03-v0.5.0.md)의 청구 정정/실제 반환/주소 경로를 유지한다.
- 관리자는 실제 수취가 아닌 선입금 오기입을 사유와 함께 무효화할 수 있다. 원 수취액·거래번호·무효화 사유는 원장에 남으며 이후 청구 후보와 차감에서는 빠진다. 활성 청구 배분이나 실제 반환이 있는 선입금은 무효화할 수 없다. 불확실한 응답은 기기에 저장된 같은 키로 재확인한다.
- 로컬 고객/게이트웨이 18/18 및 방송 Flutter 정적 분석 통과. QR 수취 안내·입금 후 배송국가 변경 예외, 실브라우저/실기기/중국망·Cloud Storage는 남는다. 운영 DB·웹에는 적용하지 않았다.
