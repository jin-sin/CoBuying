# B03-v0.2.1 · 수취 안내 청구 스냅샷

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.2.0](B03-v0.2.0.md)의 최초 청구/주소/선입금 기록은 유지한다.
- 관리자 화면에서 한국 계좌(KRW), 위챗페이·알리페이(CNY)의 수취인 명의와 텍스트 송금 안내를 저장/중지한다. 활성화에는 관리자의 실제 계정 확인 표시가 필요하다. 미확인 안내는 청구에 넣지 않는다.
- 새 청구서 발행 시 활성 안내를 `receiver_snapshots`에 저장한다. 이후 수취 설정 변경은 이전 청구서를 바꾸지 않는다. 고객은 해당 청구서에 저장된 안내를 보고 가능한 통화를 선택한다. 안내가 없는 청구서의 고객 제출 버튼은 잠근다. 보완 증빙은 이전 청구서의 안내 유무와 관계없이 제출 가능하다.
- 로컬 PGlite 고객/관리자·스냅샷 불변 시험, PostgreSQL/PostgREST HTTP, Flutter 정적 분석 통과. 실제 계정 유효성, QR 이미지, 실제 브라우저/기기, 운영 적용은 미검증이다.
- 남은 B03 필수: 청구 판본 재발행·상품 제외/재동의, 선입금 정정·반환, 입금 후 관리자 주소 정정. 단계 `v1.0.0`이나 시험 운영 가능 상태가 아니다.
