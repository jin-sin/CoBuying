# B04-v0.2.0 · 고객 제출·판매자 증빙 대조 화면

- 기록: 2026-09-28. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.1.0](B04-v0.1.0.md)의 원장/모의 업로드 검증은 보존한다.
- 고객 Flutter 정산서에 캡처 선택→비공개 업로드→송금 신고를 연결했다. 같은 화면에서 파일/키를 유지해 실패 재시도를 할 수 있고 캡처 제출만으로 입금완료를 표시하지 않는다. 판매자 Flutter 입금 확인 화면은 관리자 전용 RPC로 대기 건을 조회하고 비공개 Storage 증빙을 내려받아 실제 수취액/계정/거래번호를 입력한다. Storage 버킷 설정 파일에 manager만 해당 증빙을 읽는 RLS 정책을 준비했다.
- Flutter 정적 분석, 로컬 PGlite 입금/환불, 모의 Storage HTTP 통과. 실제 Cloud 버킷/정책·실브라우저 파일 업로드/다운로드, 보완 증빙, 위챗/알리페이 수취 안내 스냅샷 및 실제 수취 대조는 미검증이다. 운영 DB·Storage·배포는 변경하지 않았다.
