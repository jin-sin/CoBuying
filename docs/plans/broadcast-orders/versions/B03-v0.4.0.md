# B03-v0.4.0 · 청구 수정 요청·선입금 반환·주소 정정

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.3.0](B03-v0.3.0.md) 이후 로컬 구현이다.
- 청구된 주문의 고객 수정 요청은 관리자가 옵션·수량·단가를 정정하거나 해당 행을 취소하면서 한 트랜잭션에서 청구를 다음 판본으로 발행하고 요청을 완료한다. 원 주문순번/원문과 옛 청구는 보존하고, 증빙·수취·발주 시작 후에는 잠근다. 관리자 화면은 불확실한 전송을 같은 키로 재확인한다.
- 실제 반환된 KRW 선입금은 미배분 잔액 범위에서 별도 원장에 기록하며 다음 청구 잔액에서 제외한다. 고객에게는 금액·일자·사유만 보여주고 거래번호는 노출하지 않는다.
- 판매자 주소 정정은 사유·전후 주소·버전을 기록하고 고객 주소변경 알림을 처리한다. 입금 후 고객 직접 수정은 계속 거절하고, 이미 출고된 주소 스냅샷은 유지한다. 배송국가 변경은 이 경로에서 거절한다.
- 로컬 고객/게이트웨이 15/15, Flutter 방송 화면 정적 분석 통과. 실제 브라우저·실기기/중국망·Cloud Storage 및 테스트 Cloud 신규 마이그레이션 적용은 미검증이다. 관리자 단독 단가 정정, 선입금 오기입 취소, QR 안내와 입금 후 국가 변경 예외는 잔여다. 운영 DB·웹에는 적용하지 않았다.
