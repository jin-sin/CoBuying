# B04-v0.1.0 · 증빙·복수입금 원장 첫 구현

- 기록: 2026-09-28. 상태: **진행 중**. 공통 문서 v2.2.0.
- 구현: `202609280007_broadcast_payments.sql`의 비공개 증빙 예약/저장 메타데이터, 고객 송금 신고, 관리자 실수취 확인, 복수 입금, 초과금 환불 예정/완료 원장. 첫 신고에서 청구 통화를 고정하고 주문 변경을 잠근다. 고객 게이트웨이에서 형식/용량/파일 서명을 확인해 비공개 Storage 업로드 후 저장 확정한다. 버킷 설정 파일은 별도로 준비했다.
- 검증: PGlite에서 미저장 증빙 신고 거절, 15,000+3,000+1,000원 확인, 1,000원 초과 환불, 원 주문 잠금. 로컬 모의 Storage HTTP에서 업로드/재시도·쿠키/출처·파일 형식. PostgreSQL/PostgREST 마이그레이션 회귀.
- 남음: 실제 Supabase 비공개 버킷 적용/업로드 실증, 판매자 증빙 열람·보완 요청, 고객 파일 선택/송금 UI, 입금 통화/계좌 안내 화면, 실제 수취 대조 실무 UX. 실수취 확인은 외부 계좌와 대조했다는 관리자 명령이며 캡처만으로 자동 완료되지 않는다. 전체 B04 또는 MVP 완료가 아니다.
