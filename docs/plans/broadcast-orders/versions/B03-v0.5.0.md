# B03-v0.5.0 · 판매자 단독 청구 정정과 전량 취소

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.4.0](B03-v0.4.0.md)의 고객 요청·반환·주소 경로를 유지한다.
- 청구된 행의 판매자 입력 실수는 고객 요청 없이 관리자 화면에서 색상·사이즈·수량·단가를 정정하고 새 청구 판본을 발행한다. 서버는 판본·입금 잠금·권한·멱등 키를 확인하며 옛 청구와 원 주문을 보존한다. 청구의 마지막 행을 취소하면 빈 새 청구서를 만들지 않고 기존 청구를 `void`로 무효화한다.
- 로컬 고객/게이트웨이 17/17과 Flutter 방송 화면 정적 분석 통과. QR 안내, 선입금 오기입 취소, 입금 후 배송국가 변경 예외, 실브라우저·실기기/중국망·Cloud Storage는 남는다. 운영 DB·웹에는 적용하지 않았다.
