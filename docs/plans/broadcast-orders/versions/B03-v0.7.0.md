# B03-v0.7.0 · 비공개 수취 QR 안내

- 기록: 2026-09-29. 상태: **진행 중**. 공통 문서 v2.2.0. [v0.6.0](B03-v0.6.0.md)의 청구·선입금·주소 기능을 유지한다.
- 위챗페이/알리페이 QR은 판매자 권한으로 비공개 버킷에 2MB 이하 PNG/JPG를 업로드하고 서버가 실제 파일 존재를 확인한 뒤 수취 설정에 연결한다. 수취 정보 변경 시 기존 QR 연결을 해제한다. 청구에는 발행 시점의 QR ID와 형식이 고정된다.
- 고객 게이트웨이는 활성 기기 세션과 해당 고객의 현재 청구를 확인한 뒤 비공개 이미지를 전달한다. QR을 공개 URL로 만들지 않으며 고객 A가 B의 청구 QR을 얻지 못한다. 로컬 DB·게이트웨이 19/19 및 Flutter 정적 분석 통과.
- 실제 Supabase Storage 버킷/정책 적용, 실제 이미지 업로드·다운로드, 중국 브라우저/기기·운영 수취 계정 검증은 남는다. 운영 DB·웹에는 적용하지 않았다.
