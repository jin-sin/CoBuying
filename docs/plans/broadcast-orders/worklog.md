### B09 실기기용 임시 HTTPS 환경 준비 · 2026-09-29 / Codex

- 담당/범위: Codex. 시작 전 git 상태·작업표·인계와 현재 코드 경로를 확인했다. 운영 DB·웹·모니터 파일을 보존하면서 격리 테스트 Supabase만 쓰는 Flutter 웹 빌드와 고객 게이트웨이의 같은 출처 임시 호스트를 준비한다.
- 공식 Cloudflare 임시 터널을 통해 테스트 호스트의 외부 HTTPS 연결과 `/__health`, Flutter 로그인/고객 접근 화면을 확인했다. 390px 폭에서도 두 첫 화면이 맞게 배치됐다. 고객 API는 링크만으로 401, 다른 Origin POST는 403을 반환했다. Flutter는 기존 hash 라우팅이므로 직원 링크에 `/#/seller/broadcast`를 써야 한다. 터널 주소는 무작위·임시이며 이 컴퓨터와 프로세스가 켜져 있는 동안만 유효하다. 테스트 호스트는 시작 4시간 후 자동 종료한다.
- 테스트 로그인은 현재 별도 테스트 프로젝트에서 꺼져 있다. 세 기기 로그인, 판매자 테스트 계정 권한, 실제 고객 링크·승인, 실기기 화면 확인은 아직 미완료다. 테스트 중 임시 익명 로그인 변경에 대한 사용자 응답을 기다리는 동안 독립적인 화면/보안 검증을 진행한다. 단계 [B09-v0.2.3](versions/B09-v0.2.3.md)은 진행 중이다.
