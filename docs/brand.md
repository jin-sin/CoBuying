# 오렌담마켓 브랜드 기준과 이름 검토 기록

갱신: 2026-09-13 / Codex / D8. 사용자가 **정식명 오렌담마켓 · 축약명 오렌담 · 영문 ORENDAM**을 선택하고 실제 서비스 반영을 지시했다. 아래 이름 조사는 공개 검색을 통한 예비 검토이며, 브랜드 채택을 상표 등록 가능·권리 비침해 판정으로 해석하지 않는다.

## 서비스명과 운영 사업자

- 정식명: **오렌담마켓**. 서비스 화면 제목·워드마크·약관·사업자정보·Android/iOS 앱 표시명에 사용한다.
- 축약명: **오렌담**. PWA `short_name`과 iOS 웹 홈 화면용 메타에 사용한다. 처음 방문한 고객이 보는 서비스명과 법적 고지는 정식명으로 표시한다.
- 영문: **ORENDAM**. 영문 브랜드 표기와 iOS `CFBundleName`에 사용한다. `Orange Market`·`Orendam Market` 등으로 혼용하지 않는다.
- 주황색과 오렌지 슬라이스 아이콘은 유지한다. Flutter 정식명·축약명·영문·워드마크는 `ServiceBrand`에서 관리한다.
- 기존 코드에 기재된 사업자 상호: 오렌지맨. 상호 변경 서류를 확인하지 않았으므로 이 값은 보존한다. 등록부의 현재 상태를 이번 작업에서 조회·확인한 것은 아니다.
- 약관은 ‘운영 사업자가 제공하는 오렌담마켓 서비스’로, 개인정보처리방침은 서비스 운영·개인정보 처리 주체로 표시한다. 사업자정보에는 서비스명과 상호를 각각 보여준다. 거래 책임·결제 주체를 브랜드 변경만으로 바꾸지 않는다.
- 전자상거래법 제10조는 소비자가 사업자의 신원을 알 수 있도록 표시하도록 정한다. 따라서 브랜드명 변경을 사업자 상호 변경으로 추정하지 않는다. [국가법령정보센터 조문](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027063189).
- 법적 고지의 최종 문안 수정일은 2026-09-13이다. 브랜드와 운영 사업자를 구분하는 문구는 D8에서 2026-09-13 운영 웹에 반영했다. 기존 문안의 시행일은 2026-07-20이었다. 별도 공지 발송이나 사업자등록부 대조를 수행한 것은 아니며, 새로운 방송 주문의 법적 정책을 이번 브랜드 변경으로 이미 적용한 것으로 보지 않는다.

## 이전 이름 조사: 오렌지마켓 · 2026-09-13 / D6

아래는 이전 후보를 조사했던 기록이다. 현재 서비스 표기로 사용하지 않는다.

**이름 중복과 검색 혼동 가능성이 있다.** 오렌지마켓이라는 이름의 생활용품 판매 업체 프로필과, 전자상거래 소매업/해외직구대행 업체의 공개 기업정보를 확인했다. 소매·거래와 가까운 분야의 사용 사례이므로 출시 전에 확인할 가치가 크다는 판단이다. 현재 영업 여부나 상표권 보유 여부까지 확인한 것은 아니다. [업체가 등록한 당근 프로필](https://www.daangn.com/kr/local-profile/%EC%98%A4%EB%A0%8C%EC%A7%80%EB%A7%88%EC%BC%93-4433zbgk5m2w/), [전자상거래 업체 기업정보](https://www.saramin.co.kr/zf_user/company-info/view/csn/VU85YzlCYmdTcm9HQmlHL0doc1pQdz09/company_nm/%EC%98%A4%EB%A0%8C%EC%A7%80%EB%A7%88%EC%BC%93), [해외직구대행 업체 기업정보](https://www.saramin.co.kr/zf_user/company-info/view/csn/aEk5cXZhYTk3NXdzVkxiTHIwb3pWdz09/company_nm/%EC%98%A4%EB%A0%8C%EC%A7%80%EB%A7%88%EC%BC%93).

**동일 상호가 검색된다는 사실만으로 사용 불가라고 결론낼 수는 없다.** 동일·유사 상표와 상품/서비스의 관계, 권리 상태 등을 별도로 검토해야 한다. 이번 작업에서는 KIPRIS의 상표 개별 출원/등록 원부를 대조하지 않았으므로 ‘등록 상표 없음’, ‘안전하게 사용 가능’으로 안내하지 않는다. [공식 상표 제도 안내](https://www.kipo.go.kr/ko/kpoContentView.do?menuCd=SCD0200154), [KIPRIS 검색 도움말](https://www.kipris.or.kr/khome/board/help/basic.do).

출시명 확정 시 한글 붙임/띄어쓰기(오렌지마켓·오렌지 마켓), 영문(Orange Market·OrangeMarket), 유사 발음과 로고를 비교하고 실제 제공할 소매·온라인 중개·소프트웨어 서비스 범위에 맞춰 상표를 조사한다. KIPRIS 개별 권리의 상태·지정상품을 확인하고 필요하면 변리사에게 선행상표 검토를 맡긴다. 앱스토어·도메인·SNS 이름 확보 여부도 별개이며 이번에 등록하거나 확보하지 않았다. 중국에서 브랜드를 전개할 때의 중국 상표·중문 이름 검토도 아직 수행하지 않았다.

## 당시 대안 후보 · D6

D6 당시 아래 후보를 제안했다. 이후 D7 조회와 사용자 선택을 거쳐 D8에서 오렌담마켓을 서비스 브랜드로 채택했다. 상표·도메인 사용 가능성이 확정된 것은 아니다.

| 순서 | 이름 | 추천 이유 | 남는 과제 |
|---|---|---|---|
| 1 | 오렌담마켓 | 오렌지 이미지와 ‘담다’를 연결해 현재 색상·아이콘을 이어가기 좋다 | 아래 후속 예비 조회 완료. 근접 이름과 지정상품/서비스의 유사성 검토 필요 |
| 2 | 같이담마켓 | 함께 담는 공동구매 성격을 한글로 전달한다 | 일반 표현과 유사한 이름까지 조사하고 검색 구분 가능성 확인 |

정확한 후보명과 축약형을 공개 검색했으나 이번 검색에서 직접 관련된 결과를 확보하지 못했다. 이는 미사용·미등록의 증명이 아니다. 함께 검토한 ‘모아온마켓’은 이미 전자상거래 업체 정보가 확인되어 추천에서 제외했다. [해당 기업정보](https://www.saramin.co.kr/zf_user/company-info/view/csn/U0F2L1N0OXdyVm0wMGJuRXlWZUgrZz09/company_nm/%EB%AA%A8%EC%95%84%EC%98%A8%EB%A7%88%EC%BC%93).

### 오렌담마켓 후속 확인 · 2026-09-13 / D7

사용자의 추가 요청으로 KIPRIS 국내 상표를 직접 조회했다. 상품류 제한 없이 권리구분·유형·행정상태 전체에서 `오렌담마켓`, `오렌담`, `ORENDAM`, `오랜담`은 각각 검색 결과 0건이었다. 근접 이름 `오렌다`·`ORENDA`에는 등록 상표가 있으며, 별도로 옥션에서 의류·잡화를 판매하는 ‘오렌다몰’도 확인했다. ‘오렌다’ 화장품 상표 1건은 상세 지정상품까지 확인했다.

**예비 조회 결과이며 상표 사용 가능성을 확정하지 않는다.** 검색 조건·건수·근접 출원번호·지정상품 확인 범위·출처와 미확인 사항은 [오렌담마켓 이름 확인 기록](research/2026-09-13-orendam-name-check.md)에 남겼다. D7은 조회만 수행했으며, 이후 사용자가 D8에서 서비스 반영을 지시했다. 추가 권리 조사 항목은 브랜드 채택 후에도 남는다.

## 표기 선택 · D8

고객이 쇼핑 서비스임을 이해하기 쉽다는 기준으로 오렌담마켓 → 오렌담 → 오랜담 → ORENDAM 순서를 제안했고, 사용자가 정식명·축약명·영문을 함께 사용하는 안을 선택했다. ORENDAM은 영문 보조 표기이며 순위가 별도 브랜드의 권리 안전성 순서를 뜻하지 않는다. ‘오랜담’은 서비스 표기로 채택하지 않았다.

## 운영 반영 · 2026-09-13 / D8

- 운영 웹: [오렌담마켓](https://shop.orange-man.xyz/). 실제 `lib/main.dart` 릴리즈 빌드로 배포했다. 홈·로그인·약관·사업자정보의 새 이름과 서비스/상호 구분을 확인했다. 웹/PWA 이름·축약명도 배포 파일에 포함됐다.
- 점검 안내: `orange-man-maintenance`, 버전 `e29ffc6d-0f1b-41fc-8309-919d9b7d3167`. 쇼핑 사이트 제목만 새 이름으로 바꿨고 사진 사이트의 이름은 유지했다.
- Android/iOS: 프로젝트 표시명 변경 완료. 앱스토어 제출·설치 앱 업데이트는 수행하지 않았으므로 다음 네이티브 배포에서 반영한다. 외부 로그인 제공자·PG 콘솔의 등록 명칭은 변경하지 않았다.
- 방송 주문 시안은 문서 폴더에 유지하며 운영 웹 번들에는 포함하지 않았다. 모니터 Worker는 미배포이며 실거래·DB 변경·고객 메시지 발송은 수행하지 않았다.

운영 웹의 배포 전 백업은 NAS의 `/volume1/docker/cobuying-web/backup-before-orendam-1789264742.tar.gz`, 검증한 새 파일은 `/volume1/docker/cobuying-web/stage-orendam-1789264742`에 있다. 복구 시 백업의 `html/` 내용을 기존 웹 디렉터리에 복원하고 원본 응답·정적 파일을 다시 확인한다. 웹 루트 디렉터리 자체는 nginx의 마운트 대상이므로 교체하지 않는다. 점검 안내의 직전 버전은 `54e1b95d-682d-4e56-befa-06c07303fdec`이며 필요 시 해당 버전으로 롤백한다. 복구 작업은 실행하지 않았다.
