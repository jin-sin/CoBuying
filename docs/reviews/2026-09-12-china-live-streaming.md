# 중국 시청자를 위한 라이브 도입 검토 — 2026-09-12

상태: 요구사항 및 도입 조건 검토. 서비스 선정·구현·계정 가입·배포는 하지 않았다.

## 이후 변경된 우선순위

사용자는 핵심 목적이 수동 주문 업무의 전산화·자동화라고 설명했다. **고객이 다른 플랫폼에서 방송을 보더라도 오렌담마켓 웹·앱에서 주문할 수 있는 흐름을 먼저 만든다.** 자체 라이브는 선행 조건이 아니며, 도입하더라도 국내만 우선 제공해도 된다. 중국 자체 라이브는 후순위로 둔다.

현재 작업은 [외부 방송과 연결되는 주문 전산화](../product-direction.md)를 따른다. 아래 영상망 조사 내용과 시험 순서는 향후 중국 자체 라이브를 재검토할 때 참고한다.

## 2026-09-13 심층 검토 보완

한국 **개인사업자**, **한국 매장 송출**, 예상 동시 시청자 **100명 이상**, 예산은 규모별 비용을 보고 결정한다는 조건이 추가 확인됐다. [심층 검토 보고서](../research/2026-09-13-china-live-streaming-feasibility.md)에 TRTC·Agora의 상품별 요금, 개인사업자 인증의 미확인 범위, 모바일 브라우저 제한, 공급사 문의 초안과 연길 시험 기준을 정리했다.

한국 개인사업자의 본토 서비스 활성화 승인이나 중국 회선의 품질이 확인된 것은 아니다. 이 조사로 주문 전산화 우선순위를 변경하거나 자체 라이브 도입을 확정하지 않는다.

## 조사 당시 사용자에게 확인된 요구사항

- 사용자의 배우자가 셀러이며, 실제 라이브 판매를 테스트할 예정이다.
- 중국에서도 라이브를 안정적으로 시청할 수 있어야 한다. 끊김 최소화가 핵심 요구다.
- 기존 사진 사이트 `https://photo.orange-man.xyz/`에 대해 중국 고객의 반응이 엇갈린다. 일부는 잘 보이고 일부는 로딩이 오래 걸린다고 한다.
- 주요 고객 도시는 **연길로 추정**된다(사용자 답변).
- VPN을 사용하는 고객과 사용하지 않는 고객이 섞여 있지만, **VPN 없이 접속·시청할 수 있어야 한다. 일반 브라우저 이용을 희망한다.**
- 중국 현지 사업자나 협력업체는 현재 없다.
- 아내 또는 플랫폼 운영자 명의의 **한국 사업자등록은 있다**(사용자 확인). 2026-09-13 **개인사업자**로 확인했으며, 공급사의 해당 서류 인정 여부는 미확인이다.

## 기존 제안에서 달라진 점

앞선 일반적인 라이브 도입 논의에서는 기존 Cloudflare 사용 맥락을 고려해 Cloudflare Stream을 후보로 제안했다. 중국 본토 시청이 필수가 된 현재에는 이를 우선안으로 확정할 수 없다.

Cloudflare China Network는 Enterprise 고객용 별도 구독이며 도메인별 ICP 등록 요건이 있다. 공식 지원 제품 목록에서 Stream은 확인되지 않았다. 따라서 일반 Cloudflare 프록시나 Stream 구독이 중국 본토 내 영상 전송망을 제공한다고 가정하면 안 된다.

근거: [China Network 개요](https://developers.cloudflare.com/china-network/), [지원 제품 목록](https://developers.cloudflare.com/china-network/reference/available-products/).

## 사진 사이트에서 실제 확인한 범위

로컬 환경에서 공개 홈페이지의 DNS·HTTP 응답만 확인했다. 중국 본토 측정 서버는 사용하지 않았다.

| 항목 | 결과 |
| --- | --- |
| 공개 홈페이지 | HTTP 200 |
| 응답 서버 | Cloudflare |
| 해당 요청의 거점 | `cf-ray`의 `SIN` 표시 — 싱가포르 |
| 해당 HTML의 캐시 상태 | `DYNAMIC` |
| 별도 1회 GET 요청 | 첫 응답 약 1.04초, HTML 약 19KB |

이 결과로 중국 고객의 접속 경로·사진 다운로드 속도·라이브 시청 품질을 판단할 수 없다. HTML의 캐시 상태를 사진 전체의 캐시 상태로 일반화해서도 안 된다.

가능한 원인은 중국 고객의 지역·통신사별 해외 접속 경로, 시간대별 혼잡, 사진 크기·캐시, 원본 서버 응답 등이다. 아직 어느 원인인지 진단하지 않았다. Cloudflare도 중국 외부를 경유하는 트래픽의 지연·안정성 문제를 설명한다([공식 설명](https://developers.cloudflare.com/china-network/)).

## 검토할 영상 전송 방식

### 우선 검토: 브라우저용 실시간 영상 SDK

현지 사업자가 없는 조건에서는 SDK로 영상 서비스의 통신망에 연결하는 방식도 검토할 가치가 있다. 아래 내용은 가입 가능성과 품질을 보장하는 선정 결과가 아니라 공식 문서에서 확인한 후보 조건이다.

- **Tencent TRTC RTC Engine:** Web SDK에서 방송자·시청자 역할의 라이브 모드를 지원한다. [브라우저 라이브 모드](https://trtc.io/document/48424)
- TRTC는 앱별로 중국 본토 서비스를 활성화할 수 있지만, 개인·미인증 계정은 본토 노드 활성화를 지원하지 않으며 기업 인증을 요구한다. [본토 서비스 활성화 조건](https://trtc.io/document/56173)
- Tencent Cloud International은 계정 등록 국가/지역의 정부가 발행한 사업자 서류로 기업 인증 신청을 받는다. 사용자는 한국 사업자등록이 있다고 확인했다. **보유 서류의 인정 여부와 이번 판매 용도로 본토 서비스를 실제 활성화할 수 있는지는 아직 확인되지 않았다.** [국제계정 기업 인증](https://www-sg.tencentcloud.com/pt/document/product/378/10496)
- **Agora RTC:** 공식 Web 문서의 미디어 영역에 중국 본토(`CHINA`)가 포함되며, 기본값은 가까운 서비스 서버를 선택한다. 한국 계정의 본토 이용 조건과 상업 방송 조건은 별도 확인이 필요하다. [미디어 영역 설명](https://docs.agora.io/en/realtime-media/rtc/build/manage-connection-and-quality/geofencing)

TRTC Web SDK 시험을 우선 검토하고, 실제 계정 조건이 맞지 않거나 연길 회선 품질이 부족하면 다른 후보를 비교한다. 기업 인증은 특정 영상 서비스의 이용 조건이며, 아래 CDN 도메인 ICP 등록 또는 사업 전체의 인허가와 같은 절차가 아니다.

### 비교 경로: 본인 도메인을 사용하는 라이브 CDN

해외 송출을 중국 본토까지 전달하는 CDN 서비스도 비교하되, 도메인 등록 조건을 먼저 확인한다.

- **Alibaba Cloud ApsaraVideo Live:** 공식 문서에 해외 송출자 → 중국 본토 시청자 구성이 있다. 이 구성은 재생 도메인에 Global 가속과 ICP 등록을 요구한다. [국경 간 라이브 구성](https://www.alibabacloud.com/help/en/live/use-cases/how-to-get-started-with-live-streaming-outside-the-chinese-mainland)
- **Tencent Cloud CSS:** 본토를 포함하는 재생 영역은 도메인 ICP 등록이 필요하다. 중국 본토와 해외에서 함께 시청하려면 Global 구성을 검토해야 한다. 공식 문서상 해외·홍콩·마카오·대만 전용 영역은 중국 본토 요청의 정상 재생을 지원하지 않는다. [재생 영역 설정](https://cloud.tencent.com/document/product/267/32835)
- **Cloudflare Stream:** 본토 시청 품질과 제공 범위에 관한 추가 확인 및 실제 회선 테스트 전에는 선정하지 않는다.

위 CDN 구성의 ICP는 중국 본토 서비스에 필요한 등록 절차다. 서비스별 가입 주체·도메인·콘텐츠 요건은 공급사 확인이 필요하며, 이 문서는 해당 사업의 모든 인허가 요건을 판정하지 않는다. 현지 사업자 또는 협력업체가 없는 현재 조건에서 이 경로를 즉시 이용할 수 있다고 가정하지 않는다.

홍콩 서버를 사용하는 것만으로 중국 본토에서의 안정성을 보장하지 않는다. 본토 CDN 구성이 어렵다면, 가입 가능한 중국 현지 라이브 플랫폼에서 먼저 방송을 검증하는 경로도 검토한다. 특정 현지 플랫폼의 가입 자격이나 판매 기능은 이번에 조사하지 않았다.

## 권장 검증 순서

1. 연길 고객의 통신사, Wi-Fi·모바일 데이터, 실제 브라우저를 확인한다. VPN을 끈 상태를 필수 시험 조건으로 삼는다.
2. TRTC의 해외 개인사업자 인증·본토 서비스 활성화 가능 여부를 확인한다. CDN 방식도 비교할 경우에는 해당 도메인 요건을 별도로 확인한다. 한국 매장 송출과 동시 시청자 100명 이상 조건으로 비교한다.
3. 실제 연길 고객 소수에게 30~60분짜리 영상 재생 시험을 한다. 서로 다른 통신사·Wi-Fi·모바일 데이터와 실제 판매 예정 시간대를 포함한다.
4. 재생 성공 여부, 첫 화면까지의 시간, 멈춘 횟수·지속 시간, 송출과 재생 사이의 지연을 기록한다. 자동 화질 전환과 재연결도 확인한다.
5. 같은 기기에서 판매 페이지 열기 → 상품 선택 → 로그인 → 주문까지 확인한다. 영상 전송망을 개선해도 NAS 기반 웹·API나 외부 로그인 의존성의 접속 품질은 별도다.
6. 이 결과를 보고 영상 서비스를 선정하고 Flutter 판매방·상품 고정·채팅·주문을 연동한다.

초기에는 720p와 더 낮은 화질을 함께 시험하고, 약간의 재생 지연을 허용해 끊김을 줄이는 방향을 검토한다. 이는 시험 설계 제안이며 특정 서비스의 품질 보증이나 사용자와 합의된 수치가 아니다.
